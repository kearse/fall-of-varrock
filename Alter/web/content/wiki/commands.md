Every command on the server is a `::command` you type into the chat box. To see the ones **you** can use, type:

```
::commands
```

This opens the **command window** in the centre of your screen - the same place you'd read the **Book of Commands** from your starter kit. Instead of dumping a wall of text into the chat box, it lays everything out cleanly.

## How it's laid out

- **Tabs down the left** - one for each set of commands you have access to. You only ever see commands you can actually run.
- **The list on the right** shows each command in that tab with a short description of what it does. Long lists scroll - use your mouse wheel.
- **Click any command** to drop it into your chat box, ready for you to type any arguments and press enter.

## Closing it

Click the **✕** in the top-right corner, or click anywhere outside the window.

> The list is generated live from the server, so it always matches exactly what's available - new commands show up automatically.
